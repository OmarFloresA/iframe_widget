Widget IFrame URL

Este módulo añade un widget personalizado llamado iframe_url para Odoo 19 que permite mostrar campos de tipo texto (conteniendo URLs) como iframes embebidos directamente en las vistas de formulario.

Características

  • Altura fija de 600px con ancho responsive (100%)
  • Diseño limpio sin bordes
  • Muestra mensaje informativo cuando no hay URL configurada
  • Integración nativa con el sistema de widgets de Odoo

Uso

En el modelo Python:

from odoo import models, fields

class MiModelo(models.Model):
    _name = 'mi.modelo'
    _description = 'Mi Modelo'
    
    url = fields.Char(string='URL Externa')

En la vista XML:

<field name="url" widget="iframe_url"/>

Instalación

  1. Copia la carpeta iframe_widget en tu directorio de addons
  2. Actualiza la lista de aplicaciones en Odoo
  3. Instala el módulo "Widget IFrame URL"

Personalización

Para modificar las dimensiones del iframe, edita el archivo:
iframe_widget/static/src/xml/iframe_url_widget.xml
